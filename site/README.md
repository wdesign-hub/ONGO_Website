# ONGO website (static)

Open `index.html` in a browser. No build step.

Pages: `index`, `how-it-works`, `prices`, `areas`, `help`, `about`, `contact`, `delete-account`, `terms`, `privacy`.
Shared files: `assets/site.css`, `assets/site.js` (theme, menu, reveal), `assets/map.js` (Doha map, used on `index` and `areas`), `assets/img/`.

Anything highlighted `[CONFIRM …]` is a fact still to be filled in (contact details, company details, policies).
`terms.html` and `privacy.html` are drafts and need legal review before publishing.
